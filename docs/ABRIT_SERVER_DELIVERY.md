# نتیجهٔ استقرار پنل و آماده‌سازی انتقال

سرور فعلی: `10.0.0.150`، Ubuntu 24.04 x86_64. کد توسعه روی شاخهٔ `feat/abritdesk-responsive-preview` قرار دارد؛ شاخهٔ upstream master تغییر نکرده است.

پنل داخلی: `https://10.0.0.150/admin`. API و پنل مستقل از سرویس اتصال و با حساب `manager` اجرا می‌شوند. رمز SSH و کلیدهای هویت اتصال تغییر نکرده‌اند؛ هش فایل‌های اصلی قبل و بعد تطبیق داشت و فرایندهای hbbs/hbbr بدون restart باقی ماندند. حساب پنل، گواهی محلی و secret نشست جداگانه ایجاد شدند؛ اطلاعات محرمانه و بستهٔ انتقال روی GitHub قرار ندارند.

نسخهٔ ویندوز 1.5.2 از کامیت `a31ac58b0` در [Release پیش‌نمایش](https://github.com/mahdihz05/rustdesk/releases/tag/abritdesk-v1.5.2-control-preview.1) منتشر شد. انتشار تأییدشدهٔ 1.5.0 همچنان Latest است تا مسیر عمومی API و تست اتصال واقعی تأیید شوند. سیاست فعلی پنل latest=1.5.2، minimum=0.0.0 و mandatory=false است.

آزمون‌ها: ۱۲ تست پنل/انتقال در سرور و CI، ۲۳ تست Flutter، ۶ تست مدل Rust، اجرای واقعی ویندوز با ۵۶ تصویر بدون خطای ثبت‌شده و تطبیق هش ۱۰۴ فایل بسته. ورود واقعی مدیر، cookie امن، رسانه، API و ETag/304 روی TLS محلیِ تأییدشده با گواهی همان سرور بررسی شدند. تست‌های الزام نسخه در محیط جدا انجام شدند و سیاست مسدودکننده روی کاربران سرور فعال نشد.

بستهٔ نهایی خصوصی: `/srv/abritdesk-transfer/abritdesk-transfer-20261005-133617.tar.gz`.
SHA256: `09b08d8cc9d7d489102d704a01f4e24f499e2b8b771617c24737efdbe39404b3`.
نسخه‌ای از بسته برای مالک در پوشهٔ preview محلی ذخیره شد. فایل‌ها، snapshot سازگار هر دو دیتابیس و هویت سرور داخل بسته تأیید شدند؛ ابزار بازیابی نیز بازنویسی سرور فعلی را رد کرد. بازیابی عملی روی سرور تازه هنوز اجرا نشده است. پیش از مهاجرت چند ماه بعد، باید بستهٔ تازه از داده‌های همان زمان گرفت؛ [راهنمای انتقال](../server/abrit-control/README.md).

مانع بیرونی: DNS عمومی دامنهٔ `serverdesk.abrit.cloud` به `2.180.18.102` می‌رود؛ HTTPS آن گواهی پیش‌فرض خودامضای pfSense و پاسخ 503 نشان داد. وب‌سرویس داخل سرور روی ۴۴۳ آماده است، اما مسیر عمومی و گواهی معتبر به تنظیم Reverse Proxy وابسته‌اند. DNS و تنظیمات pfSense/Cloudflare تغییر نکردند. خاموش‌کردن اعتبارسنجی TLS در برنامه انجام نشد. تست کامل بنر زنده و آپدیت از کلاینت تا API عمومی باید بعد از رفع این مسیر انجام شود.

## سطح تغییرات در فایل‌های قبلی

| فایل قبلی | مسیر رفتار تغییرکرده و ضرورت |
| --- | --- |
| `.github/workflows/abritdesk-windows-preview.yml` | endpoint API به دامنهٔ سرور فعلی تغییر کرد؛ تغییرهای فقط پنل/اسناد از بیلد سنگین Windows کنار گذاشته شدند |
| `Cargo.toml` و `Cargo.lock` | فقط نسخهٔ محصول به 1.5.2 افزایش یافت تا بیلد دارای endpoint صحیح از 1.5.1 قبلی قابل تشخیص باشد؛ وابستگی Rust تغییر نکرد |
| `flutter/pubspec.yaml` | نسخهٔ رابط و منابع خروجی به 1.5.2+70 هماهنگ شد |
| `src/abrit_policy/runtime.rs` | فقط نگهداری اتصال بیکار HTTP API خاموش شد تا بررسی بعدی در انتقال DNS اتصال تازه بسازد؛ مسیر پروتکل اتصال اصلی تغییر نکرد |
| `res/abrit/client-manifest.example.json` | نمونه با endpoint، تصویر محلی و لینک انتشار صحیح 1.5.2 هماهنگ شد و اجبار پیش‌فرض خاموش ماند |
| `docs/ABRIT_CLIENT_API.md` و `docs/ABRIT_UI.md` | قرارداد endpoint جدید و پیوند راهنمای پنل/انتقال اضافه شد؛ اثر اجرایی ندارند |

منطق پنل، داده‌ها، آزمون‌ها و انتقال در پوشهٔ مستقل جدید `server/abrit-control` و CI سبک آن قرار دارد. روی میزبان فقط پیش‌نیازهای جدید nginx/venv، حساب سرویس بدون shell و فایل‌ها و سرویس جداگانهٔ پنل اضافه شدند. فایل‌ها و تنظیمات سرویس اتصال موجود، SSH، رمز root، DNS و firewall تغییر نکردند.
